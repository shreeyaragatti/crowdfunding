================================================================================
                           HOW TO USE DEV MODE
================================================================================

STEP 1: Start the App
  $ npm run dev
  Open: http://localhost:3000

STEP 2: Enable Dev Mode
  - Look for toggle: "🔧 Development Mode (Bypass Payment Verification)"
  - Click to turn ON (switch becomes teal/green)
  - You'll see: "✓ Dev mode enabled: You can create campaigns..."

STEP 3: Create Test Campaign
  - Click "Create Campaign" button
  - Fill in the form:
    * Campaign Name: Any name (e.g., "Test Campaign")
    * Minimum Contribution: 0.01 ETH (any amount)
    * Description: Any description
    * Image: Upload file or paste URL
    * Target Amount: 1 ETH (any amount)
  - Click "Create"
  - Success! Campaign created without blockchain verification

STEP 4: Disable Dev Mode (When Done Testing)
  - Toggle back to OFF
  - Normal production mode resumes
  - MetaMask connection required again

================================================================================
                        TROUBLESHOOTING
================================================================================

Issue: Toggle not showing?
  → Clear browser cache (Ctrl+Shift+Delete)
  → Hard refresh (Ctrl+Shift+R)
  → Check console for errors

Issue: Campaign not creating?
  → Check browser console (F12) for error messages
  → Verify image URL is valid
  → Try using a public image URL

Issue: Want to reset?
  → Run in console: window.localStorage.removeItem('betterfund:devMode')
  → Refresh page: location.reload()

Issue: Image upload fails?
  → Dev mode uses placeholder automatically
  → Campaign still creates successfully
  → Check console logs for details
