QUICK START (2 minutes)
================================================================================

1. Start App
   npm run dev
   Open: http://localhost:3000

2. Enable Toggle
   Look for: "🔧 Development Mode" (below heading)
   Toggle: ON (turns teal)
   See: "✓ Dev mode enabled..."

3. Create Campaign
   Click: "Create Campaign"
   Fill: Name, Description, Image, Target
   Note: NO WALLET NEEDED
   Click: "Create"
   Result: "✓ Campaign created (Dev Mode)"

4. See on Home Page
   Redirects: To home page
   Look for: Your campaign with "🔧 Dev Mode" badge
   Color: Yellow styling (not teal)
   Order: Newest campaigns first

WHAT DEV MODE CHANGES
================================================================================

ENABLED (Dev Mode ON)
  ❌ Wallet: NOT required
  ❌ Blockchain: NO transaction
  ❌ Gas: NO cost
  ✅ Speed: Instant
  ✅ Campaigns: Unlimited
  ✅ Database: Saved to Supabase

DISABLED (Normal Mode)
  ✅ Wallet: Required
  ✅ Blockchain: Real transaction
  ✅ Gas: Real cost
  ⏱️  Speed: Block time (~15s)
  ⚠️  Campaigns: Depends on funds
  ✅ Database: On-chain contract

WHAT HAPPENS WHEN YOU CREATE IN DEV MODE
================================================================================

USER ACTION                    SYSTEM ACTION
─────────────────────────────────────────────────────────────────────────
Click "Create Campaign"    →   Form opens (no wallet check)
Fill form fields           →   Validation only
Click "Create"             →   POST to API (devMode=true)
API processes              →   Saves to Supabase (no blockchain)
Success toast              →   Shows "Campaign created (Dev Mode)"
Redirect to home           →   Home page reloads
Fetch campaigns            →   GET /api/campaign-metadata
Display                    →   Shows campaign with 🔧 badge
Done                       →   Campaign appears in list

================================================================================
TROUBLESHOOTING
================================================================================

Problem: Toggle not showing
  Solution: 
    1. Hard refresh (Ctrl+Shift+R)
    2. Clear cache (Ctrl+Shift+Delete)
    3. Try incognito window

Problem: Campaign not creating
  Solution:
    1. Check console (F12) for errors
    2. Ensure image URL is accessible
    3. Check all form fields are filled
    4. Try with different image URL

Problem: Campaign not appearing on home
  Solution:
    1. Refresh page (F5)
    2. Check browser console for fetch errors
    3. Verify Supabase credentials in .env
    4. Check API response in Network tab

Problem: Want to disable dev mode
  Solution:
    1. Toggle switch back OFF
    2. Or run in console:
       window.localStorage.removeItem('betterfund:devMode');

================================================================================
API ENDPOINTS
================================================================================

GET /api/campaign-metadata
  Returns: List of dev mode campaigns
  Example:
    curl http://localhost:3000/api/campaign-metadata
  Response:
    { campaigns: [...] }

POST /api/campaign-metadata
  Saves: New campaign metadata
  Body: { contractAddress, creator, name, targetWei, devMode, ... }
  Response: { campaign: {...} }

IMPORTANT NOTES
================================================================================

🔧 Dev Mode is CLIENT-SIDE ONLY
   - No server configuration needed
   - Works in development and production
   - Users can enable/disable anytime
   - No impact on real campaigns

💾 DATA IS PERSISTED
   - Dev campaigns saved to Supabase
   - Survive browser refresh
   - Survive browser restart
   - Only cleared with cache clear

🔐 NO SECURITY ISSUES
   - Dev mode doesn't bypass validation
   - All data validated normally
   - Supabase permissions respected
   - No sensitive data exposed

⚡ PERFORMANCE IMPACT
   - Minimal (< 50ms per page load)
   - One extra API call to fetch campaigns
   - No blockchain RPC calls in dev mode
   - Scales to many campaigns
